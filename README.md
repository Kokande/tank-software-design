# tank-software-design

Запуск со случайным уровнем `./gradlew run`.
Выбор уровня:
- `./gradlew run --args="--random"`
- `./gradlew run --args="--level level.dat"`

Структура Java-пакетов внутри `ru.mipt.bit.platformer`:

| Пакет | Ответственность |
| --- | --- |
| `controls` | Общая стратегия управления и выполнение команд |
| `controls.commands` | Команды движения, стрельбы и переключения полосок здоровья |
| `controls.keyboard` | Состояние клавиатуры, привязки клавиш и управление с клавиатуры |
| `controls.ai` | Случайное управление и адаптация рекомендованных действий |
| `mechanics` | Жизненный цикл игрового мира, объектов и событий; интерфейс стрельбы |
| `mechanics.collision` | Проверка препятствий, занятых клеток и границ уровня |
| `mechanics.movement` | Направления и интерфейс движения |
| `graphics` | Общий интерфейс отрисовки и отображение игрового мира |
| `graphics.objects` | Отрисовка танков, деревьев и снарядов |
| `graphics.health` | Декоратор полоски здоровья и состояние её видимости |
| `objects` | Игровые объекты: танк, дерево и снаряд |
| `level` | Описание и генерация уровней |
| `util` | Вспомогательные функции LibGDX и интерполяция движения |

Тесты в `src/test/java` повторяют структуру основных пакетов. Общая тестовая
клавиатура находится в `controls.support`, а интеграционные тесты управления —
в `controls`.
